# Melodi Launcher

Panel de contrôle pour gérer le serveur du logiciel Melodi sans passer par les lignes de commandes.

## 🚀 Fonctionnalités

- **Gestion du serveur** : Démarrer, arrêter et redémarrer le serveur Melodi
- **Surveillance** : Visualiser l'état actuel du serveur et les logs en temps réel
- **Configuration** : Modifier les paramètres du serveur facilement
- **Interface intuitive** : Design moderne et facile à utiliser
