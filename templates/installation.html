Installation des Composants

Déployez les briques et services logiciels sur le serveur sélectionné.

M

MELODI ERP

Application ERP Principale

Déploie l'application MELODI ERP dans /opt/melodi avec son environnement virtuel Python et génère l'unité systemd melodi.service.

PG

PostgreSQL

Base de données Relationnelle

Installe les paquets système postgresql postgresql-contrib via apt et active le service au démarrage.

RD

Redis Server

Cache & Message Broker

Installe le paquet apt redis-server et démarre le serveur de cache mémoire.

NG

Nginx Web Server

Proxy Inverse HTTP

Installe le paquet apt nginx, valide la configuration initiale et active le service systemd.
